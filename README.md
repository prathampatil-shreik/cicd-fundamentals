# CI/CD Fundamentals — Spring Boot App

A minimal Spring Boot REST application used to learn CI/CD and Monitoring & Logging basics end to end:
local run → Docker → GitHub Actions → ECR → ECS Fargate → CloudWatch Logs.

---

## Application

A Spring Boot web application that exposes three HTTP endpoints. Every request generates an INFO-level log. The `/error-test` endpoint deliberately generates an ERROR-level log used for CloudWatch metric filter testing.

---

## Endpoints

| Endpoint      | Method | Response                              | Status |
|---------------|--------|---------------------------------------|--------|
| `/`           | GET    | `Welcome to my CI/CD Pipeline Project!` | 200  |
| `/health`     | GET    | `OK`                                  | 200    |
| `/error-test` | GET    | `Test error generated`                | 500    |

- `/error-test` is intentionally used to generate a deliberate ERROR log for the monitoring project.

## Run Locally

**Windows:**
```
cd app
.\mvnw.cmd spring-boot:run
```

**Linux/macOS:**
```
cd app
./mvnw spring-boot:run
```

App starts on `http://localhost:8080`

**Build JAR:**
```
cd app
.\mvnw.cmd clean package
```

## Testing

Generate traffic against all three endpoints:

```bash
curl http://localhost:8080/
curl http://localhost:8080/health
curl http://localhost:8080/error-test
```

`/error-test` is intentionally used to generate a deliberate HTTP 500 error and ERROR log for the monitoring project.

---

## Logging

Every request produces an INFO log:

```
2025-01-01 12:00:00 INFO  [Ci_Cd_fundamentals.Ci_Cd_fundamentals.HelloController] - Request received: GET /
2025-01-01 12:00:01 INFO  [Ci_Cd_fundamentals.Ci_Cd_fundamentals.HelloController] - Request received: GET /health
2025-01-01 12:00:02 INFO  [Ci_Cd_fundamentals.Ci_Cd_fundamentals.HelloController] - Request received: GET /error-test
```

The `/error-test` endpoint also produces a distinctive ERROR log:

```
2025-01-01 12:00:02 ERROR [Ci_Cd_fundamentals.Ci_Cd_fundamentals.HelloController] - ERROR TEST: Deliberate application error generated by /error-test
```

The pattern `ERROR TEST: Deliberate application error generated by /error-test` is used later as a **CloudWatch Logs metric filter** to count application errors.

## CI/CD Pipeline

Every push to `main` automatically:
1. Runs tests
2. Builds the JAR
3. Builds the Docker image
4. Pushes to Amazon ECR with `latest` and commit SHA tags

## Deployment

App runs on **ECS Fargate** pulling the image from ECR.
See `docs/deployment-summary.md` for full details and rollback steps.
